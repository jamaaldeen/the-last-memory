\# The Last Memory



An AI-powered cinematic memory generator built with Livepeer Agent.



Users describe a memory, idea, or moment they want to visualize, and the application uses Livepeer Agent to generate visual media and transform it into a cinematic video.



\## Hackathon Track



\*\*Track 1 — Livepeer Agent Builder\*\*



\## What It Does



The core experience is simple:



\*\*Describe a memory → Generate → Watch it come to life.\*\*



A user enters a description of a memory or imagined moment. The application sends that concept through Livepeer Agent's creative media capabilities, generating imagery and animating it into a short cinematic video.



The resulting video is displayed directly inside the application.



\## Why The Last Memory?



The video-generation capability is presented through an original interactive sci-fi experience called \*\*The Last Memory\*\*.



The story follows Mara, a mother exploring a futuristic memory archive and discovering that parts of her daughter's memory were intentionally removed.



This narrative is a creative demonstration of what generated memories could feel like inside an actual product rather than simply presenting video generation as a standalone tool.



The story is a personal creative addition to the project and is not competition-provided content.



\## Livepeer Agent



Livepeer Agent is central to the application's media-generation workflow.



The application uses Livepeer Agent to:



1\. Generate imagery from a user's memory description.

2\. Animate the generated imagery into cinematic video.

3\. Return the resulting media to the application for the user to experience.



\## Main Experiences



\### Create Your Own Memory



Users can enter any memory, scene, idea, or imagined moment and generate a cinematic video from it.



\### The Last Memory



The featured narrative demonstrates the technology through an interactive sci-fi story about memory, loss, and deliberately forgotten moments.
